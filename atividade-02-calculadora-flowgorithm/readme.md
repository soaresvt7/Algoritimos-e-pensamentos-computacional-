# 🧮 Calculadora com 20 Funções - Flowgorithm

## 📚 Descrição

Este projeto consiste no desenvolvimento de uma calculadora com 20 funções matemáticas e práticas, utilizando o **Flowgorithm**.

O projeto foi desenvolvido como atividade acadêmica com o objetivo de aplicar conceitos básicos de **algoritmos, lógica de programação, variáveis, operações matemáticas, estruturas condicionais e estruturas de repetição**.

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma calculadora capaz de realizar diferentes tipos de operações, utilizando uma estrutura de programação visual por meio de fluxogramas.

Além dos cálculos básicos, foram implementadas funções relacionadas à geometria, conversão de temperatura, porcentagem, IMC, juros simples e regra de três.

## 🛠️ Ferramenta utilizada

- **Flowgorithm**
- Fluxograma
- Lógica de programação
- Algoritmos matemáticos

## 💻 Funcionamento

Ao iniciar o programa, o usuário recebe um menu com as 20 opções disponíveis.

O usuário deve escolher uma opção e, em seguida, informar os valores solicitados pelo programa.

Após realizar o cálculo, o resultado é apresentado na tela.
