# 🧮 Calculadora com 20 Funções - C

## 📚 Descrição

Este projeto consiste no desenvolvimento de uma calculadora com 20 funções, utilizando a linguagem de programação **C**.

O projeto foi desenvolvido com o objetivo de aplicar conceitos fundamentais de **lógica de programação, variáveis, entrada e saída de dados, estruturas condicionais, estruturas de repetição e operações matemáticas**.

## 🎯 Objetivo

Desenvolver uma calculadora capaz de realizar diferentes operações matemáticas e cálculos do dia a dia, utilizando conceitos básicos da linguagem C.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Compilador C
- GitHub

## 📋 Funções da calculadora

A calculadora possui 20 funções:

1. ➕ Soma
2. ➖ Subtração
3. ✖️ Multiplicação
4. ➗ Divisão
5. 🔢 Potência
6. ➗ Resto da divisão
7. 📊 Porcentagem
8. 📈 Média aritmética
9. 🔢 Fatorial
10. ◻️ Área do quadrado
11. ▭ Área do retângulo
12. 🔺 Área do triângulo
13. ⭕ Área do círculo
14. 📏 Perímetro do quadrado
15. 📏 Perímetro do retângulo
16. 🌡️ Celsius para Fahrenheit
17. 🌡️ Fahrenheit para Celsius
18. ⚖️ Cálculo de IMC
19. 💰 Juros simples
20. 📐 Regra de três

## 💻 Funcionamento

Ao iniciar o programa, é apresentado um menu contendo as 20 funções disponíveis.

O usuário escolhe uma opção e informa os valores solicitados. O programa realiza o cálculo e apresenta o resultado na tela.

### Exemplo

```text
========================================
       CALCULADORA - 20 FUNCOES
========================================

Digite 1 para Soma
Digite 2 para Subtracao
Digite 3 para Multiplicacao
...
Digite 20 para Regra de tres

Escolha uma opcao: 1

Digite o primeiro valor: 10
