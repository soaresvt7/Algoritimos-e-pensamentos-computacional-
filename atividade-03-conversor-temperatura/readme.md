# 🌡️ Conversor de Temperatura em C

## 📚 Descrição

Este projeto consiste em um conversor de temperaturas desenvolvido na linguagem de programação **C**.

O programa permite realizar conversões entre as escalas **Celsius, Fahrenheit e Kelvin**, utilizando um menu de opções.

O projeto foi desenvolvido como atividade prática em aula, com o objetivo de aplicar conceitos básicos da linguagem C e de lógica de programação.

## 🎯 Objetivo

Desenvolver um programa capaz de converter temperaturas entre diferentes escalas, utilizando estruturas de decisão e operações matemáticas.

## 🛠️ Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Estrutura `switch/case`
- GitHub

## 🌡️ Conversões disponíveis

O programa possui 6 opções de conversão:

1. Celsius → Fahrenheit
2. Celsius → Kelvin
3. Fahrenheit → Celsius
4. Fahrenheit → Kelvin
5. Kelvin → Fahrenheit
6. Kelvin → Celsius

## 💻 Funcionamento

Ao iniciar o programa, é apresentado um menu com as opções de conversão.

O usuário escolhe uma das opções e informa a temperatura que deseja converter.

O programa realiza o cálculo correspondente e apresenta o resultado na tela.
