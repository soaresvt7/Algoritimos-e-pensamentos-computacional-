# Algoritimos-e-pensamentos-computacional-
 Calculadora com 20 Funções

 Objetivo

Desenvolver uma calculadora utilizando conceitos fundamentais de programação, estruturas de decisão, entrada e saída de dados, variáveis, operações matemáticas e estruturas de repetição.

 Tecnologias utilizadas

- Flowgorithm
- Lógica de programação
- GitHub

Funcionalidades

A calculadora possui 20 funções:

1. Soma
2. Subtração
3. Multiplicação
4. Divisão
5. Potência
6. Resto da divisão
7. Porcentagem
8. Média aritmética
9. Fatorial
10. Área do quadrado
11. Área do retângulo
12. Área do triângulo
13. Área do círculo
14. Perímetro do quadrado
15. Perímetro do retângulo
16. Celsius para Fahrenheit
17. Fahrenheit para Celsius
18. Cálculo de IMC
19. Juros simples
20. Regra de três

Como executar

1. Baixe o arquivo `.fprg` disponível neste repositório.
2. Abra o arquivo utilizando o **Flowgorithm**.
3. Execute o programa.
4. Escolha uma das 20 opções disponíveis no menu.
5. Informe os valores solicitados pelo programa.
